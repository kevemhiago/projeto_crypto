# ⚡ CryptoPunk Monitor

![Status](https://img.shields.io/badge/Status-Online-brightgreen) ![Python](https://img.shields.io/badge/Made%20with-Python-blue)

Um dashboard de monitoramento de criptomoedas em tempo real com estética Cyberpunk, construído inteiramente em Python.

## 📸 O Projeto
Este painel consome dados de múltiplas APIs (CoinCap, CoinGecko e Binance) para garantir que o serviço nunca saia do ar, utilizando uma lógica de fallback ("Highlander").

### 🚀 Funcionalidades
- **Monitoramento em Tempo Real:** Bitcoin, Ethereum e Solana.
- **Multi-API Fallback:** Se uma API falha, o sistema troca automaticamente para a próxima.
- **Visual Cyberpunk:** Estilização via CSS Injection com efeitos Neon e fonte Orbitron.
- **Responsivo:** Funciona perfeitamente em Desktop e Mobile.

## 🛠️ Tecnologias Utilizadas
- **Python 3.9+**
- **Streamlit** (Frontend e Deploy)
- **Plotly** (Visualização de Dados Interativa)
- **Pandas** (Manipulação de Dados)
